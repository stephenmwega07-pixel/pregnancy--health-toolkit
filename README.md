# 🤰 Pregnancy Health Toolkit

A responsive web application designed to support expecting mothers with health tracking tools, due date calculations, and pregnancy management resources.

## 🚀 Features

- **Due Date Calculator**: Estimate your due date based on the first day of your last menstrual period (LMP).
- **Interactive UI**: Simple, clean interface tailored for quick access to vital pregnancy health tools.
- **JavaScript Integration**: Light, efficient script execution for instant calculations.
